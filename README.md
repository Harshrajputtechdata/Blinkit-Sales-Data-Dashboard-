# Blinkit Sales Data Dashboard | Power BI

An interactive Power BI dashboard built to explore Blinkit grocery sales data and present business metrics in a clear, visual format.

## 📌 Project Overview

This project uses Microsoft Power BI to analyze Blinkit sales data and explore sales performance across product categories and outlet characteristics.

## 🎯 Objectives

- Analyze overall sales performance.
- Compare sales across item types and fat-content categories.
- Explore outlet location, size, and type.
- Present business metrics through interactive visualizations.
- Demonstrate practical Power BI and data analytics skills.

## 📊 Dashboard Highlights

- Total Sales
- Average Sales
- Item-related metrics
- Ratings
- Sales by Item Type
- Sales by Fat Content
- Outlet-level sales comparisons

*Exact metric definitions and results should be verified in the Power BI report.*
